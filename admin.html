How updating works
  1. Pick an activity on the left, or click New activity. Changes save in this browser as you type.
  2. Fill in English and French side by side. French can be left blank: the site shows the English text until it's added.
  3. When you're done, either Download activities.json and upload it to the data folder of your GitHub repository, or use Publish to GitHub to save it there directly. The live site updates within a minute or two.

Publish to GitHub

This saves data/activities.json straight to your repository. You need a GitHub fine-grained personal access token with Contents: Read and write permission for this repository only (GitHub → Settings → Developer settings → Personal access tokens). The token is sent only to GitHub.
